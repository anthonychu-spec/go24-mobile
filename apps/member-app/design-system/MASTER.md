## 2. Visual Style

**"Elevated Athletic Minimal"**

- Clean white surfaces dominate — let content breathe
- Bold red brand moments (hero cards, CTAs, accents) not decoration
- Generous whitespace — premium feels spacious, not cramped
- Inter Black for display/stats — conveys strength, confidence
- Ionicons outline (inactive) → filled (active) — consistent icon discipline
- No emojis as structural icons — vector only

### Anti-patterns to avoid
- ❌ Dark backgrounds on non-hero sections
- ❌ Mixing filled + outline icons at same hierarchy level
- ❌ Raw hex values in component StyleSheet
- ❌ Emoji as navigation/structural icons
- ❌ Cards without consistent shadow elevation

// Import from: src/theme/colors

### Color usage rules
- **Red** = brand primary, 1 primary CTA per screen max
- **Orange** = booking actions only (Book, Cancel, Waitlist)
- **Green** = success states, available spots, streaks
- **Teal** = check-in / health metrics
- **Indigo** = class bookings / schedule
- **Amber** = PT sessions / payment warnings

## 4. Typography Scale

```ts
// Import from: src/theme/typography (type)
// Display
type.display   // 48px Black — hero stats (total visits, streak milestones)
type.stat      // 34px Black — large dashboard numbers
type.statSm    // 26px Black — card-level stats

// Headings
type.h1        // 30px Black — screen titles
type.h2        // 24px Black — section headings
type.h3        // 20px Bold  — card headings, class names
type.h4        // 17px Bold  — list item titles, modal headings

// Body
type.body      // 15px Regular — standard body copy
type.bodySm    // 13px Regular — secondary info, metadata
type.bodyBold  // 15px Bold    — emphasized body

// Labels & UI
type.label     // 13px SemiBold — form labels, badges
type.labelSm   // 11px SemiBold — small badges, chips
type.overline  // 10px Bold CAPS 1.5 letter-spacing — section headers
type.tab       // 10px SemiBold — tab bar labels

// Buttons
type.btnLg     // 16px Bold 0.3 tracking — primary CTA
type.btnMd     // 14px Bold — standard button
type.btnSm     // 13px SemiBold — small button

// Caption
type.caption   // 12px Regular — timestamps, helper text
```

### Typography rules
- **Minimum body**: 15px (avoids iOS auto-zoom, meets readability)
- **Line height**: 1.5–1.75× for body, tighter for display/headings
- **Letter spacing**: loose for OVERLINE (+1.5), tight for display (-0.5 to -1)
- **Weight hierarchy**: Black (900) display → Bold (700) headings → Regular (400) body

## 5. Spacing System

```ts
// Import from: src/theme/spacing
spacing.xs   = 4   // Icon gaps, inline padding
spacing.sm   = 8   // Tight spacing, chip gaps
spacing.md   = 12  // List item padding
spacing.base = 16  // Screen horizontal padding (standard)
spacing.lg   = 20  // Card internal padding
spacing.xl   = 24  // Section gaps, modal padding
spacing['2xl'] = 32  // Large section gaps
spacing['3xl'] = 40  // Hero section padding
```

### Spacing rules
- All spacing uses 4pt grid (multiples of 4)
- Screen horizontal padding: always `screenPadding` (16)
- Gap between sections: `spacing.xl` (24) minimum
- Card internal: `spacing.lg` (20) standard

## 7. Shadows / Elevation

```ts
// Import from: src/theme/shadows
shadows.hairline  // Almost flat — list items
shadows.card      // Standard card elevation
shadows.modal     // Bottom sheets, modals
shadows.cta(color) // Colored glow for primary CTAs
```

### Shadow rules
- Cards always use `shadows.card`
- Never use raw `shadowOpacity`/`elevation` values in screens
- CTA buttons use `shadows.cta(colors.primary)`
- Modals/sheets use `shadows.modal`

## 8. Components

All reusable components live in `src/components/` and barrel-export via `src/components/index.ts`.

| Component | When to use |
|-----------|-------------|
| `<Button>` | All interactive actions — never custom Pressable + Text |
| `<Card>` | All card containers — standardises shadow + radius |
| `<Input>` | All text inputs — ensures labels, error states |
| `<Avatar>` | All user initials — consistent sizing |
| `<Badge>` | All status labels — semantic color variants |
| `<ListRow>` | All menu/settings rows — icon + label + chevron |
| `<SectionHeader>` | Section overline labels |
| `<EmptyState>` | All empty/no-data states |
| `<ScreenHeader>` | All sub-screen headers (back + title + right action) |
| `<ScreenWrapper>` | Root wrapper — every screen |

### Component import pattern
```ts
import { Button, Card, Input, Badge, Avatar, ListRow, EmptyState, ScreenHeader, ScreenWrapper } from '../src/components';
import { colors, spacing, type, radius, shadows } from '../src/theme';
```

## 9. Screen Patterns

### Tab screens (Home/Classes/Activity/PT/Settings)
```
<ScreenWrapper>
  <Custom header (not ScreenHeader)>
  <ScrollView or FlatList>
    sections with spacing.xl gaps
  </ScrollView>
</ScreenWrapper>
```

### Sub-screens (Membership/Payment/Booking detail)
```
<ScreenWrapper>
  <ScreenHeader showBack title="..." />
  <ScrollView>
    <Card> sections </Card>
  </ScrollView>
</ScreenWrapper>
```

### Modals / Bottom sheets
```
borderTopLeftRadius: radius['2xl'] or radius['3xl']
scrim: rgba(0,0,0,0.45)
handle: 40px wide, 4px tall, colors.border
```

## 10. UX Rules (Priority Checklist)

### P1 — Accessibility
- [ ] All icons have `accessibilityLabel`
- [ ] Minimum text contrast 4.5:1 (`colors.text` on `colors.card` = ✅)
- [ ] Touch targets ≥44pt (use `hitSlop` where needed)

### P2 — Touch & Interaction
- [ ] All `Pressable` show pressed feedback (opacity/scale)
- [ ] All async buttons show loading state + are disabled during load
- [ ] `hitSlop={8}` on small icon buttons

### P4 — Style Consistency
- [ ] No emojis as structural icons
- [ ] One primary CTA per screen max
- [ ] Consistent `shadows.card` on all card surfaces
- [ ] All icons from `@expo/vector-icons` Ionicons set

### P6 — Typography
- [ ] Use `type.*` presets, never raw fontSize + fontFamily
- [ ] Section labels use `type.overline`
- [ ] Body text minimum 15px (`type.body`)

### P9 — Navigation
- [ ] Tab bar: 5 items max (✅ currently 5)
- [ ] All sub-screens have `<ScreenHeader showBack>`
- [ ] Back behavior predictable and consistent
